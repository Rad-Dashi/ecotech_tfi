Este es un programa para la evaluación del curso de Python.

El código principal y sus pruebas de impresión por consola pueden verificarse en los scripts que se encuentran dentro de sustentabilidad:
- logica_catalogo.py 
- logica_sensores.py 
- logica_emisiones.py 

Para ver el programa en funcionamiento, instalar las librerías listadas en requirements.txt creando primero un venv con `python -m venv venv` y luego `pip install -r requirements.txt`.
Luego, ejecutar `python manage.py runserver` y acceder a la dirección del servidor que aparecerá en consola (por defecto, http://127.0.0.1:8000/).
